# Security Policy

## Reporting a vulnerability

Please report security issues privately by e-mail to **support@ramzx.de**
(subject: "RamzX Unlock security"). Please do not open a public issue for vulnerabilities.

We will confirm receipt and keep you informed about the fix.

## Scope

- Handling of the Windows Hello key and the encrypted unlock records
- Anything that could expose KeePass key material or change a database file

See the *Honest security notes* in [README.md](README.md) for known, documented limitations
(for example: Windows Hello always allows the PIN).
