**Miftawerk Unlock** إضافة مجانية ومفتوحة المصدر لبرنامج إدارة كلمات السر **KeePass 2**.
تتيح لك فتح قاعدة بيانات KeePass عبر **Windows Hello** – **بالتعرف على الوجه أو ببصمة الإصبع
أو برمز PIN** – بدلاً من كتابة كلمة السر الرئيسية في كل مرة.
مفتاح Windows Hello محفوظ في شريحة **TPM**، والفتح السريع **ينتهي تلقائياً**،
و**يُقفل KeePass عند قفل Windows**.

> **الحالة: نسخة تجريبية (Alpha).** تعمل في اختباراتنا على Windows 11 بالوجه والبصمة.
> يُرجى استخدامها مع قاعدة بيانات تجريبية حتى صدور أول نسخة موقّعة.

## المزايا

- 🔓 **الفتح عبر Windows Hello** – بالوجه أو البصمة أو PIN مباشرة في نافذة KeePass
- 🔐 **مفتاح داخل TPM** – يُنشئه Windows، والإضافة لا تستلم إلا التوقيع
- ⏱️ **انتهاء تلقائي** – بعد 7 أيام أو عند إعادة تشغيل Windows
- 🔒 **يُقفل مع Windows** – عند Win+L أو قطع الجلسة أو وضع السكون *(قيد الاختبار)*
- 🗂️ **لكل قاعدة بيانات وبموافقتك فقط** – الخيار الافتراضي «لا»
- 💾 **لا يعدّل ملف ‎.kdbx أبداً**
- 🛟 **آمن عند الخطأ** – الإلغاء أو أي خطأ يعيدك إلى نافذة كلمة السر المعتادة
- 🚫 **بدون أي تتبّع** – لا اتصال بالإنترنت ولا جمع بيانات

## كيف يعمل

1. افتح قاعدة البيانات مرة واحدة بكلمة السر الرئيسية كالمعتاد.
2. تسألك الإضافة: «تفعيل الفتح السريع عبر Windows Hello لهذه القاعدة؟»
3. في المرة القادمة يظهر Windows Hello – انظر إلى الكاميرا أو المس قارئ البصمة، وتُفتح القاعدة.
4. بعد 7 أيام أو بعد إعادة تشغيل Windows تُطلب كلمة السر الرئيسية من جديد.

## أسئلة شائعة

**هل يمكن فتح KeePass ببصمة الإصبع أو بالوجه؟**
نعم، عبر إضافة. KeePass 2 لا يدعم Windows Hello مباشرة، وMiftawerk Unlock تضيف ذلك.

**هل Windows Hello عامل تحقق ثانٍ لـ KeePass؟**
لا – ونقولها بوضوح. Windows Hello يقبل دائماً رمز PIN أيضاً. من يعرف رمز PIN ويستطيع
استخدام جلسة Windows الخاصة بك يمكنه فتح القاعدة المفعّلة طالما أن الفتح السريع صالح.
إنها **ميزة للراحة**. وضع YubiKey كعامل ثانٍ حقيقي مخطط له.

**هل ترى الإضافة بياناتي البيومترية؟**
لا. التعرف يتم بالكامل داخل Windows Hello، وبحسب Microsoft لا تغادر البيانات البيومترية الجهاز.
الإضافة تستلم توقيعاً فقط.
